# apps-claude

Coleção de apps pessoais feitos com o Claude. Cada app fica em sua própria
subpasta e pode ser publicado pelo GitHub Pages.

## Apps

### [rota-de-vida](./rota-de-vida/)
App do casal (Mattheus & noiva) para acompanhar o plano de vida: rota
financeira (Rota A × Rota B), diário de bordo, mentalidade, ambiente e metas.
É um PWA instalável na tela inicial do celular, com atualização automática.

- Publicado em: `https://moraesmattheus.github.io/apps-claude/rota-de-vida/`
- Detalhes e instruções: [rota-de-vida/README.md](./rota-de-vida/README.md)
